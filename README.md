# Descripción

IndiePlay es un catálogo de videojuegos construido como aplicación de una sola página (SPA) en React. Muestra una colección de juegos en formato de tarjetas, cada una con su carátula, estudio/autor, género, calificación y una breve descripción.

El proyecto está dividido en componentes reutilizables, cada uno con una única responsabilidad, y usa props para pasar los datos de cada juego sin repetir código.

# Publicación en GitHub Pages

El sitio se compila y publica automáticamente al hacer push a la rama `main`.
En GitHub, configura **Settings → Pages → Build and deployment → Source** como
**GitHub Actions**. La URL del sitio es:

https://diana1022004.github.io/indieplay-catalogo/
